# 📤 发布指南（Obsidian → Enveloppe → 博客）

本站用 **Enveloppe** 插件，从 Obsidian 一键发布笔记到 GitHub，自动部署。

---

## 一、博客文章 front-matter 模板

在 Obsidian 笔记**最前面**写上这段（用属性面板加属性，别手敲），`---` 之间是配置：

```yaml
---
share: true
target: blog/posts/你的文章名
date: 2026-02-20
categories:
  - 随笔
comments: true
title: 你的文章名
---
```

**正文从这里开始**。

---

## 二、每个属性的类型（Obsidian 属性面板里选对）

| 属性 | 属性类型 | 效果 |
|---|---|---|
| `share` | **复选框** ☑ | `share: true`（发布开关） |
| `comments` | **复选框** ☑ | `comments: true`（开 giscus 评论） |
| `target` | **文本** | `target: blog/posts/xxx`（路由） |
| `date` | **日期** | `date: 2026-02-20`（必填，博客排序用） |
| `categories` | **列表** ⛓ | `categories:` 下缩进 `- 随笔`（**必须是列表！**） |
| `title` | **文本** | `title: 我的文章`（会作为文件名和标题） |

> ⚠️ **最容易踩的坑**：`categories` 一定要选「**列表**」，不要选「文本」。选成文本会变成 `categories: "- 随笔"`（字符串），导致部署失败。

---

## 三、属性详解

### `share`（发布开关）
- `true` → 会被 Enveloppe 推送到仓库
- 不写或 `false` → 不会发布
- **不想发的笔记千万别写 `share: true`**

### `target`（路由到哪个目录）
| target 值 | 最终位置 |
|---|---|
| `blog/posts/xxx` | `docs/blog/posts/xxx.md`（博客文章） |
| `notes/crypto` | `docs/notes/crypto.md`（学习笔记） |

> `target` 决定发布到站点哪个区。`blog/posts` 是博客，`notes` 是笔记。

### `date`（必填）
Material 博客插件按日期归档/排序，**不能省**。格式 `YYYY-MM-DD`。

### `categories`（分类，列表）
博客插件按分类筛选。示例：
```yaml
categories:
  - 随笔
  - CTF
```

### `comments`（评论）
`true` 开启 giscus 评论（需站点已装 giscus）。

### `title`（标题/文件名）
作为页面标题和发布后的文件名。可选（默认用笔记文件名）。

## 四、图片怎么放

Obsidian 里用嵌入语法（`![[城堡到工业区的远眺.jpg]]` 或 `![[城堡到工业区的远眺.jpg|备注]]`）：
```markdown
![[城堡到工业区的远眺.jpg]]
```

- `|` 后面是 **alt 替代文本**（自动加文件名那个，无害，别去删）
- 图片会被 Enveloppe 自动复制到 `docs/assets/images/`
- 确保 Enveloppe 的**附件目录**设为 **`docs/assets/images/`**

---

## 五、Enveloppe 常用命令（`Ctrl+P` 搜 `upload` / `enveloppe`）

| 命令 | 作用 |
|---|---|
| **Upload single current active note** | 推送当前打开的这篇（最常用） |
| **Upload all notes** | 推送所有 `share: true` 的笔记（一键全发） |
| **Upload unpublished notes** | 只推还没发布过的 |
| **Refresh all published notes** | 重新推送所有（改版后全量同步） |
| **Test the connection** | 测试 GitHub 连接（代理是否生效） |
| **Check the rate limit** | 查 GitHub API 限额 |

---

## 六、发布流程

1. 写好笔记，front-matter 用上面的模板（`categories` 用**列表**）
2. 想先看效果：**Enveloppe → Test mode 打开** → Upload → 看模拟路径是否正确
3. 没问题后：**关掉 Test mode** → 右键/命令面板 **Upload single current active note**
4. 推送后约 1-2 分钟自动部署，刷新 `https://bishouyou.github.io/bishou-blog/` 查看

---

## 七、网络 / 代理提示

- Enveloppe 走 GitHub API，需配一个**全局代理**（Obsidian 插件 `Global Proxy`）
- 代理类型：socks 优先，http/https 兜底（本机端口见代理客户端设置）
- 代理若不通，用 Enveloppe 的「Test connection」排查
- GitHub token：勾 **`repo`** 作用域即可，**不用** `workflow`

---

## 八、GitHub 连接配置速记

| 项 | 值 |
|---|---|
| API Type | Free/Pro/Team (default) |
| GitHub username | `bishouyou` |
| Repository name | `bishou-blog` |
| Main branch | `main` |
| Automatically merge pull requests | ✅ 开 |
| GitHub token | PAT，仅 `repo` 作用域 |

**文件树路由**（Upload configuration）：
| 项 | 值 |
|---|---|
| File tree in repository | **Property key** |
| Property key | `target` |
| Root folder | `docs` |
| Attachment folder | `docs/assets/images/` |
